# 0-20mA 电流输出模块

## 📋 项目介绍
个人学习设计的0-20mA电流输出模块，可用于工业控制、传感器信号传输、PLC模拟量输入等场景。
- 设计时间：2026年5月
- 打样焊接：2026年6月
- 设计软件：立创EDA专业版

## ⚙️ 硬件参数
| 项目 | 参数 |
|------|------|
| 输出信号 | 0-20mA 标准工业电流信号 |
| 供电电压 | 12V-24V DC 宽电压输入 |
| 控制方式 | 0-5V 电压控制输入 |
| 输出精度 | 典型值 ±0.5% FSR |
| 最大负载 | 500Ω |
| 恒流特性 | 负载0-500Ω范围内电流波动 < 0.1mA |
| 接口类型 | 接线端子，方便工业现场接线 |
| PCB层数 | 2层板 |
| 板子尺寸 | 90mm × 50mm |
